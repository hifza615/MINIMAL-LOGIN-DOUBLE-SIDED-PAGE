
🔐 Modern Login Page

A clean and modern Login Page UI built using HTML5 and CSS3. This project features a professional sign-in interface with email and password fields, social media login options, and a responsive design focused on user experience and visual appeal.

✨ Features
Modern and attractive login interface
Email and password input fields
Social media sign-in buttons
Responsive and user-friendly design
Clean layout with professional styling
Built entirely with HTML and CSS

🚀 Technologies Used
HTML5
CSS3

📚 What I Learned
Creating professional form layouts
Styling input fields and buttons
CSS Flexbox and positioning
Responsive UI design
Improving user experience through design

This project was created to practice front-end development skills by designing a sleek and modern authentication page without using any frameworks or JavaScript.
